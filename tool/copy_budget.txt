# How much user-facing English is still hardcoded under lib/.
#
# `dart run tool/hardcoded_copy.dart` prints the inventory and this number beside it,
# and `--check` fails when the total rises above it. CI runs --check, so this is the
# one line that decides whether new untranslated copy can be merged.
#
# It goes DOWN by moving wording behind `AppText`. It goes up only when someone adds a
# string a person reads without translating it, which is exactly what the check exists
# to make visible — so raising it is allowed, in a commit that says why, and doing it
# quietly is not.
#
# Lower it when a translation slice lands. A budget left far above reality is a ratchet
# that has slipped, and `hardcoded_copy_test` refuses one that drifts too far.
#
# Raised 600 -> 615 when the doctor report gained the twelve-month summary and the
# condition-names line. Those fifteen sentences are English on purpose rather than by
# omission: `simple_pdf.dart` writes Helvetica with WinAnsiEncoding and embeds no
# fonts, so a Devanagari or Arabic string has no glyphs to be drawn with. Translating
# the printable report needs embedded fonts and complex-script shaping — its own
# milestone, named in docs/report.md — and until then its prose is counted here rather
# than quietly moved behind a key that could never be filled.

# total raised 600 -> 615 (the report's twelve-month summary), see the note above
